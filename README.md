# Insertion Sort Algorithm

This repository contains my **Design and Analysis of Algorithms (DAA) Assignment 1**, implemented using Python.

## 📌 About the Project

Insertion Sort is a simple sorting algorithm that builds a sorted array one element at a time. It works by taking each element and inserting it into its correct position among the previously sorted elements.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concept:** Design and Analysis of Algorithms
- **Algorithm:** Insertion Sort

## ⚙️ How It Works

1. Accepts the number of elements from the user.
2. Takes the array elements as input.
3. Sorts the elements in ascending order using Insertion Sort.
4. Displays the sorted array.

## ⏱️ Time and Space Complexity

| Case | Time Complexity |
|---|---|
| Best Case | O(n) |
| Average Case | O(n²) |
| Worst Case | O(n²) |

- **Space Complexity:** O(1) auxiliary space, because the sorting is performed in place.
